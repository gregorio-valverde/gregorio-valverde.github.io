## Context

This project was developed as my Master's thesis in Big Data and Data Science.

The objective was to analyze whether machine learning techniques could improve electricity demand forecasting compared with more traditional time series approaches.

Electricity demand forecasting is a relevant problem because demand is variable, electricity is difficult to store at scale, and forecasting errors can create operational and economic inefficiencies.

## Project Workflow

The project followed a full machine learning workflow:

1. Data extraction from electricity demand and weather sources.
2. Data cleaning and preprocessing.
3. Exploratory data analysis.
4. Feature engineering using demand, weather, and calendar variables.
5. Model training and comparison.
6. Analysis of results and limitations.

## Models Implemented

The project compared several types of models:

- ARIMAX as a traditional statistical time series model.
- Decision Tree, Random Forest, and XGBoost as supervised machine learning models.
- LSTM as a deep learning model for sequential data.

This comparison allowed me to evaluate different trade-offs between accuracy, interpretability, computational cost, and model complexity.

## Results

XGBoost showed the best practical balance between predictive performance and computational cost.

The LSTM model showed potential, but its results were limited by processing time and the daily granularity of the data.

The project also showed that exogenous variables, especially temperature and holidays, were relevant for improving the forecasts. Other variables, such as humidity, introduced more noise and were less useful.

## What I Learned

This project helped me consolidate several important skills:

- Working with time series data.
- Building supervised learning workflows.
- Comparing statistical, machine learning, and deep learning approaches.
- Evaluating model performance beyond accuracy alone.
- Understanding the importance of feature engineering in forecasting problems.
