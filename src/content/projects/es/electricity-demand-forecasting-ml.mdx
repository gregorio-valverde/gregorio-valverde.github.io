## Contexto

Este proyecto se desarrolló como mi Trabajo Fin de Máster en Big Data y Data Science.

El objetivo era analizar si las técnicas de machine learning podían mejorar la predicción de demanda eléctrica frente a enfoques más tradicionales de series temporales.

La predicción de demanda eléctrica es un problema relevante porque la demanda es variable, la electricidad es difícil de almacenar a gran escala y los errores de previsión pueden generar ineficiencias operativas y económicas.

## Flujo del proyecto

El proyecto siguió un flujo completo de machine learning:

1. Extracción de datos de demanda eléctrica y fuentes meteorológicas.
2. Limpieza y preprocesamiento.
3. Análisis exploratorio de datos.
4. Ingeniería de variables utilizando demanda, meteorología y calendario.
5. Entrenamiento y comparación de modelos.
6. Análisis de resultados y limitaciones.

## Modelos implementados

El proyecto comparó varios tipos de modelos:

- ARIMAX como modelo estadístico tradicional de series temporales.
- Decision Tree, Random Forest y XGBoost como modelos supervisados de machine learning.
- LSTM como modelo de deep learning para datos secuenciales.

Esta comparación permitió evaluar distintos compromisos entre precisión, interpretabilidad, coste computacional y complejidad.

## Resultados

XGBoost mostró el mejor equilibrio práctico entre rendimiento predictivo y coste computacional.

El modelo LSTM mostró potencial, pero sus resultados estuvieron limitados por el tiempo de procesamiento y la granularidad diaria de los datos.

El proyecto también mostró que variables exógenas, especialmente la temperatura y los festivos, eran relevantes para mejorar las predicciones. Otras variables, como la humedad, introducían más ruido y resultaban menos útiles.

## Qué aprendí

Este proyecto me ayudó a consolidar varias competencias:

- Trabajo con series temporales.
- Construcción de flujos de aprendizaje supervisado.
- Comparación de enfoques estadísticos, de machine learning y deep learning.
- Evaluación del rendimiento más allá de una única métrica de precisión.
- Importancia de la ingeniería de variables en problemas de predicción.
